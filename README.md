# Arc Roleplay: Server Infrastructure & Operations Manual

**Role:** Owner & Lead Systems Administrator
**Status:** Ownership Transferred / Archived

## Project Status & Succession
This repository serves as an architectural and operational overview of my tenure as the Owner and Lead Systems Administrator for the Arc Roleplay server. 

Upon pivoting my career focus toward enterprise IT, I executed a full transfer of ownership of the server, its player base, and its active infrastructure to a new management team. As the proprietary Lua scripts, database configurations, and active user data transferred with the business, this repository contains the sanitized governance, procurement, and policy frameworks I established to manage the network and community.

## Repository Directory
This case study is broken down into specific operational domains. Click the files above to view the detailed policies and ledgers:

* **`acceptable-use-policy.md`** 
  Demonstrates Identity & Access Management (IAM), user provisioning requirements, and exploitation prevention (Rule of Heat, Greenzone enforcement).
* **`non-disclosure-agreement.md`** 
  Information Security (InfoSec) and intellectual property protections established for administrative staff and developers.
* **`it-procurement-and-budget.md`** 
  Financial ledgers tracking a recurring monthly operational budget, cloud hosting management (Zap Hosting), SaaS vendor subscriptions, and overall cost-recovery (P&L) metrics.
* **`incident-management-policy.md`** 
  The progressive disciplinary matrix and escalation paths utilized to enforce compliance, manage organization strikes, and handle user timeouts/bans.
* **`service-management-crm.md`** 
  IT Service Management (ITSM) workflows used to run an internal service desk (Hells Iron Motorcycles), including work order ticketing, SLA discount tiering, and granular asset pricing.

## Core Competencies Demonstrated
* **Infrastructure Management:** Cloud server hosting, uptime monitoring, and third-party software integration.
* **IT Procurement:** Software licensing, and budget tracking.
* **Governance & Compliance:** Drafting and enforcing network acceptable use policies (AUP) and strict confidentiality agreements (NDA).
* **Helpdesk & Service Management:** End-user de-escalation, conflict resolution, and tiered ticket billing.
