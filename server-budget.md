# Arc Roleplay:Procurement & Infrastructure Budgeting

## 1. Overview
As the server owner, I was responsible for managing the monthly operational budget, tracking recurring infrastructure costs, and procuring third-party software assets (scripts and plugins) 
to expand server capabilities.

## 2. Recurring Infrastructure & SaaS Subscriptions
Managed a recurring monthly operational budget of $145.40, ensuring zero lapse in server uptime and developer platform access.
* **Cloud Hosting:** Managed dedicated server hosting via Zap Hosting ($48.43/mo).
* **Platform Licensing:** Maintained active Patreon subscription licensing for the FiveM network ($18.90/mo).
* **Developer Subscriptions:** Tracked and maintained active subscriptions for third-party asset developers, including Gabz ($17.26/mo), DRC ($30.86/mo), and Pickle Mods ($29.95/mo).

## 3. Asset Management & One-Off Procurement
* Evaluated, purchased, and integrated single-license software scripts from external vendors into the live server environment. 
* Managed vendor relationships and license keys for various external developers (e.g., Apollo-Developments, LondonStudios, LegacyDMC).
* Tracked ROI and integration for premium assets, including the M.C Clubhouse map ($60.00) and the Grappler pursuit utility ($27.49).

* ## 4. Financial Tracking & Cost Recovery
Utilized spreadsheet databases to track the financial sustainability of the server infrastructure over its lifecycle.
- **P&L Management:** Monitored month-over-month Profit & Loss ledgers, balancing operational payouts against community-generated income.
- **Revenue Tracking:** Documented community funding scaling (e.g., reaching $65/month in July) to offset the baseline infrastructure costs.
- **Ledger Balancing:** Tracked tiered monthly operational payouts (scaling from $53.93 to $115.45) to ensure sustainable budget allocation for server growth and developer compensation.
